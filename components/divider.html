Divider

Línea que separa elementos dentro de una fila o bloques apilados, en cuatro grosores.

Live Preview

Resumen

El Divider es una línea que separa contenidos: vertical y corta para dividir elementos dentro de una misma fila, u horizontal y de ancho completo para separar bloques apilados. Se usa, por ejemplo, entre las filas de un resumen de compra o entre las opciones de un menú lateral.

8 variantes = Orientation (2) × Thickness (4), matriz completa. Color y grosor están ligados a variables del kit.

Propiedades

Propiedades configurables del componente Divider.

PropiedadTipoDescripción
OrientationVariantInline muestra una línea vertical corta, pensada para separar elementos dentro de una misma fila de contenido. Stack muestra una línea horizontal de ancho completo, pensada para separar bloques apilados verticalmente. Inline es el valor por defecto.
ThicknessVariantControla el grosor del trazo del divisor, de 1px (Base) a 4px (Heavy), para dar más o menos énfasis visual a la separación entre contenidos. Base es el valor por defecto.
