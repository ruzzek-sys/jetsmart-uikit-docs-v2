Icon Circle

Número o ícono contenido en un círculo, para marcar pasos o destacar un ícono.

Live Preview

Resumen

Icon Circle es un círculo que contiene un número o un ícono. Sirve para numerar pasos de una secuencia o para destacar un ícono dentro de una card o un listado, y puede llevar una etiqueta de texto debajo.

54 variantes = Style (3) × Type (3) × Size (3) × Content (2). Value, Label y Show Label son propiedades de instancia: se configuran en cada instancia y no multiplican el número de variantes.

Propiedades

Propiedades editables del componente Icon Circle.

PropiedadTipoDescripción
StyleVariantSolid rellena el círculo con color sólido. Outline deja el círculo transparente con un borde del color de Type. Ghost elimina el círculo por completo, mostrando solo el número o ícono. Solid es el valor por defecto.
TypeVariantDefine la paleta de color: Primary usa azul marino oscuro, Tertiary usa turquesa/teal, Neutral usa gris. Primary es el valor por defecto.
SizeVariantControla el tamaño del círculo: Large (52px), Medium (44px) o Small (36px). Large es el valor por defecto.
ContentVariantNumber muestra un número dentro del círculo. Icon muestra un ícono en su lugar. Number es el valor por defecto.
ValueTextTexto o número que se muestra dentro del círculo cuando Content está en Number. El valor por defecto es «1».
LabelTextTexto que aparece debajo del círculo cuando Show Label está activado. El valor por defecto es «Paso».
Show LabelBooleanMuestra u oculta el texto de Label debajo del círculo. Off (por defecto) lo oculta; On lo revela.
