Inline Message

Mensaje contextual dentro del contenido.

Live Preview

Resumen

Inline Message es un mensaje contextual que vive dentro del contenido, junto al bloque al que se refiere, para informar, advertir, confirmar o señalar un error sin interrumpir el flujo. Se compone de un icono y un texto editable, y puede ir en una sola línea compacta o expandido en varias líneas.

10 variantes = Type (5) × Layout (2). Type recorre las filas y Layout las columnas porque el componente mide 642 de ancho: con Type en columnas la matriz superaría los 3.800 px.

Propiedades

Propiedades configurables del componente Inline Message.

PropiedadTipoDescripción
TypeVariantDefine el color y la semántica del mensaje: Default (neutro), Info (azul), Warning (amarillo), Success (verde) o Error (rojo). Default es el valor por defecto.
LayoutVariantControla el formato del mensaje. Inline muestra una sola línea compacta con el texto truncado; Block expande el componente y muestra el mensaje completo en varias líneas. Inline es el valor por defecto.
MessageTextTexto del mensaje que se muestra dentro del componente. Es completamente editable y no tiene un límite de caracteres definido por el componente.
IconInstanceIcono que acompaña al mensaje. Por defecto usa el icono de información (Font Awesome) sin importar el Type seleccionado — no cambia automáticamente según el color, pero puede reemplazarse por cualquier otro icono mediante instance swap.
