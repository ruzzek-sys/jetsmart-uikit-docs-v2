Components

Buttons

Dos componentes de acción: el botón con texto y el botón circular de solo ícono. Cada uno tiene su propia matriz de variantes y sus propiedades.

Button

Botón con texto e íconos opcionales a cada lado. Es el que dispara las acciones de la interfaz, desde la principal de una pantalla hasta las secundarias.

Live Preview

Resumen

Lleva una etiqueta de texto y hasta dos íconos, uno a cada lado, que se pueden apagar desde la instancia. El peso visual se elige con Type (sólido, con borde o solo texto) y el color con Intent; Inverse adapta la paleta para usarlo sobre fondos oscuros.

216 variantes = Size (3) × State (4) × Type (3) × Intent (3) × Inverse (2). Las columnas de la matriz recorren Type, Intent e Inverse; las filas, Size y State.

Propiedades

Lo que se puede ajustar en cada instancia del botón.

PropiedadTipoDescripción
SizeVariantLarge: botón de 52px de alto. Medium: 44px de alto. Small: 36px de alto, con tipografía e íconos más compactos. Large es el valor por defecto.
StateVariantDefault: fondo navy sólido. Hover: fondo navy más oscuro al pasar el cursor. Focused: agrega un anillo azul alrededor del botón. Disabled: fondo y borde gris claro, sin interacción. Default es el valor por defecto.
TypeVariantPrimary: fondo sólido. Secondary: borde con fondo transparente. Tertiary: solo texto e ícono, sin fondo ni borde. Primary es el valor por defecto.
IntentVariantDefault: fondo navy. Emphasis: fondo rojo para acciones urgentes. Promotional: fondo naranja para contenido promocional. Default es el valor por defecto.
InverseVariantFalse: fondo oscuro y texto claro, para usar sobre fondos claros. True: invierte la paleta a fondo blanco y texto navy, para usar sobre fondos oscuros. False es el valor por defecto.
LabelTextTexto que se muestra dentro del botón. «Button» es el valor por defecto.
Show Icon LeftBooleanMuestra u oculta el ícono a la izquierda del texto; al desactivarlo, el botón se angosta. Activado por defecto.
Show Icon RightBooleanMuestra u oculta el ícono a la derecha del texto; al desactivarlo, el botón se angosta. Activado por defecto.

Icon Button

Botón circular de solo ícono, para acciones compactas donde no cabe una etiqueta. Puede mostrar un número en el centro y una insignia de notificaciones.

Live Preview

Resumen

Un círculo con un ícono central que se puede reemplazar o complementar con un número, más una insignia opcional en la esquina para señalar notificaciones pendientes. Style define si va relleno, con borde o sin fondo, e Intent elige la paleta semántica; Inverse mantiene el contraste sobre fondos oscuros.

288 variantes = Size (3) × State (4) × Style (3) × Intent (4) × Inverse (2). Las columnas de la matriz recorren Style, Intent e Inverse; las filas, Size y State.

Propiedades

Propiedades disponibles para configurar el componente Icon Button.

PropiedadTipoDescripción
SizeVariantLarge es el tamaño por defecto (52px); Medium (44px) y Small (36px) reducen proporcionalmente el botón, el ícono y el badge para contextos más compactos.
StateVariantDefault muestra el botón en reposo. Hover resalta el fill al pasar el cursor. Focused agrega un anillo exterior para navegación por teclado. Disabled reduce la opacidad indicando que la acción no está disponible. Default es el valor por defecto.
StyleVariantSolid rellena el círculo completo con el color de Intent. Outline deja el fondo transparente y solo dibuja el borde y el ícono en ese color. Ghost elimina fondo y borde, dejando solo el ícono coloreado. Solid es el valor por defecto.
IntentVariantDefine la paleta semántica: Default usa azul marino, Emphasis usa rojo para acciones críticas, Highlight usa turquesa para resaltar y Neutral usa gris para acciones secundarias. Default es el valor por defecto.
InverseVariantFalse usa la paleta estándar pensada para fondos claros. True invierte los colores para mantener el contraste sobre fondos oscuros o de color. False es el valor por defecto.
Show BadgeBooleanActiva una insignia circular roja en la esquina superior derecha para señalar notificaciones pendientes. Oculto (false) es el valor por defecto.
Badge CountTextTexto mostrado dentro de la insignia cuando Show Badge está activo, normalmente un número corto de notificaciones. Solo visible si Show Badge = True. «1» es el valor por defecto.
NumberTextTexto mostrado en el centro del botón cuando Show Number está activo; convive con el ícono si Show Icon también está activo. «1» es el valor por defecto.
Show IconBooleanMuestra u oculta el ícono central (por ejemplo, la flecha). Visible (true) es el valor por defecto.
Show NumberBooleanMuestra un número en el centro del botón, junto al ícono o en su lugar si Show Icon está desactivado. Oculto (false) es el valor por defecto.
