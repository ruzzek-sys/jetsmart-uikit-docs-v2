Dropdown Option

La fila base de un menú desplegable: una opción con texto, un elemento leading (ícono o bandera) y, opcionalmente, número de orden, código, badge contador y chevron. Es el átomo con que se arman todos los paneles de Dropdown Menu.

Resumen

Dropdown Option es la fila de un menú desplegable: una opción con texto, un elemento leading (ícono o bandera) y, opcionalmente, número de orden, código, badge contador y chevron. Es el átomo con que se arman todos los paneles de Dropdown Menu.

12 variantes = State (3) × Leading (2) × Weight (2), matriz completa. Es el átomo que componen todos los paneles de Dropdown Menu.

Dropdown Search Menu

El panel de resultados de un buscador tipo autocomplete: una lista de filas Dropdown Search Item (título, descripción y esquinas redondeadas según su posición en la lista) con scroll opcional.

Live Preview

Resumen

Dropdown Search Menu es el panel de resultados de un buscador tipo autocomplete: una lista de filas Dropdown Search Item (título, descripción y esquinas redondeadas según su posición en la lista) con scroll opcional.

El propio panel expone Scroll, que muestra u oculta la barra de scroll a la derecha. El resto de las propiedades pertenecen a la instancia anidada Dropdown Search Item y se ajustan desde el panel de esa instancia: Position controla el radio de esquinas según el lugar en la lista (Top, Middle, Bottom o Center para un ítem solo), mientras Title y Description son el texto principal y secundario de cada fila.

Propiedades

Propiedades de Dropdown Search Item (instancia anidada) · ajustables desde el panel de la instancia

PropiedadTipoDescripción
ScrollBooleanMuestra u oculta la barra de scroll a la derecha del menú. Default: activado.
PositionVariantTop: esquinas superiores redondeadas, para el primer ítem de la lista. Middle: sin radio, para ítems intermedios. Bottom: esquinas inferiores redondeadas, para el último ítem. Center: las cuatro esquinas redondeadas, para cuando el ítem está solo en la lista. Default: Top.
TitleTextTexto principal de la fila (p. ej. ciudad y código IATA). Default: «Santiago de Chile, SCL - Chile».
DescriptionTextTexto secundario debajo del título (p. ej. nombre del aeropuerto). Default: «Comodoro Arturo Merino Benítez Int.».
