Components

Radio Card

Tarjeta seleccionable de opción única.

Live Preview

Resumen

Tarjeta seleccionable que presenta una opción dentro de un grupo de elección única, con título y una línea de descripción opcional. Señala con el borde y el ícono radio si la opción está disponible, elegida, bloqueada o con error.

8 variantes = State (4) × Size (2), matriz completa. Show Description es propiedad de instancia y no abre una tercera dimensión de variantes.

Propiedades

Propiedades configurables del componente Radio Card.

PropiedadTipoDescripción
StateVariantControla el color del borde y del ícono radio. Default usa un borde neutro; Selected resalta el borde en teal con el ícono relleno; Error marca el borde en rojo; Disabled atenúa los colores de texto e ícono. Default es el valor por defecto.
SizeVariantLarge usa el ancho completo de la card, con mayor padding. Small reduce el ancho y el padding para layouts más compactos. Large es el valor por defecto.
Show DescriptionBooleanMuestra u oculta la línea de descripción debajo del título. Activado es el valor por defecto.
