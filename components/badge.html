Badge

Etiqueta compacta para estados y conteos.

Live Preview

Resumen

Etiqueta compacta que marca un estado, una categoría o un conteo. No se usa suelta: vive dentro de otros componentes —cards de vuelo, filas de selección, tablas del listado de vuelos— para calificar el elemento que la contiene.

54 variantes = Style (3) × Type (9) × Size (2). Los nueve colores se dividen en cuatro de marca (Primary, Secondary, Accent, Tertiary), cuatro utilitarios (Success, Warning, Info, Error) y Neutral, que queda aparte de ambas familias.

Propiedades

Lo que se puede ajustar en cada instancia del badge.

PropiedadTipoDescripción
StyleVariantSolid usa un fondo sólido de color con texto blanco. Subtle usa un fondo tenue del mismo color con texto y borde a juego. Outline deja el fondo transparente y solo dibuja el borde y el texto en color. Solid es el valor por defecto.
TypeVariantDefine la paleta de color del badge: Primary, Secondary, Accent, Tertiary, Neutral, Success, Warning, Info o Error. Primary es el valor por defecto.
SizeVariantMedium usa un padding y una tipografía más grandes. Small los reduce para contextos más compactos. Medium es el valor por defecto.
Show Icon LeftBooleanAgrega un ícono antes del texto. Desactivado por defecto.
Show Icon RightBooleanAgrega un ícono después del texto. Desactivado por defecto.
LabelTextTexto que muestra el badge. «Badge» por defecto.

Guía de uso

Uso del color y estados

Cómo comunica color el Badge y qué grupos existen.

AspectoCategoríaDescripción
Dos familias de colorGrupoSe agrupan en dos familias de color: Brand Colors (Primary, Secondary, Accent, Tertiary) — identidad y jerarquía de marca, con tokens color/*/brand-* — y Utility Colors (Success, Warning, Info, Error) — comunican el estado de un elemento (éxito, advertencia, información, error), con tokens color/*/utility-*. Neutral queda aparte de ambas familias: usa tokens genéricos (border/secondary, content/brand-primary) para los casos donde se necesita un badge sin carga semántica de marca ni de estado.
