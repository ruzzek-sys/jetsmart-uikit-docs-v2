Components

Radio

Botón de selección única.

Live Preview

Resumen

Botón de selección única que el usuario marca para elegir una opción dentro de un grupo, acompañado de un label editable. Se usa en formularios y selectores donde solo una alternativa puede quedar activa.

4 variantes = Selected (2) × State (2), matriz completa. El círculo es un icono del Icon Pack ligado a variables del kit.

Propiedades

Propiedades configurables del componente Radio.

PropiedadTipoDescripción
SelectedVariantTrue rellena el ícono del radio en teal y da mayor peso al label. False muestra el ícono vacío. False es el valor por defecto.
StateVariantDisabled atenúa el color del ícono y del label. Default es el valor por defecto.
LabelTextTexto del label junto al ícono. «Option» es el valor por defecto.
Show LabelBooleanMuestra u oculta el texto del label, dejando solo el ícono. Activado es el valor por defecto.
Show IconBooleanMuestra u oculta el ícono del radio, dejando solo el label. Activado es el valor por defecto.
Show RadioBooleanMuestra u oculta el componente Radio completo. Activado es el valor por defecto.
