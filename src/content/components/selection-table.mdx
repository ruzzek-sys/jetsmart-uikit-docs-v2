## Resumen

Selection Table es una tabla compacta que lista pasajeros u opciones en filas y deja elegir en cada una con un control de selección. Se usa dentro de modales y tarjetas —por ejemplo, para asignar un servicio como embarque prioritario a cada pasajero— junto a Toggle Card, Toggle Tab y la fila de total.

2 variantes = `Type` (2), matriz completa: `Radio` muestra una fila con dos opciones de selección única y `Checkbox` muestra tres filas con una columna de casillas de selección múltiple. Color, tipografía, radios y espaciados están ligados a variables del kit.
