## Resumen

File Upload Card es la tarjeta con la que el pasajero sube un archivo de respaldo, como un certificado. Muestra el nombre del pasajero con una etiqueta de estado y, debajo, una zona de arrastre que pasa a confirmar el archivo cargado o a indicar que fue rechazado.

4 variantes = `State` (4), matriz completa. Un eje: el estado de carga del archivo (`Default`, `Complete`, `Error` y `Disabled`). El componente no expone propiedades de instancia, así que el nombre del pasajero y los textos se editan entrando a las capas de la instancia. Junto a la matriz está `Attached File Chip`, un componente aparte de la tarjeta.
