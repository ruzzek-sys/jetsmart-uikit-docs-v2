About this site

Este sitio es una referencia estática del UI Kit v1.0. Cada página incluye un preview embebido desde Figma y secciones de documentación para guiar diseño e implementación.

Structure

La documentación está organizada en cinco áreas principales:

Foundations

Typography, colors, spacing, radius, elevations e icons — los building blocks del sistema.

Components

Componentes reutilizables del UI Kit: buttons, inputs, tabs y más.

Product Components

Componentes específicos del producto: flight card, searchbox widget.

Patterns

Combinaciones de componentes para flujos y experiencias completas.

Flows

Pantallas end-to-end: home, booking, administra tu vuelo y cuenta.

Figma source

El archivo fuente del design system es Jetsmart UI Kit v1.0. Cada página de componente enlaza al nodo correspondiente dentro de ese archivo.

How to use locally

Abre index.html directamente en el navegador. No requiere servidor ni build step.

  • HTML, CSS y JavaScript vanilla
  • Tailwind via CDN para layout utilitario
  • Navegación compartida desde nav-data.js
