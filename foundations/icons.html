Icons

Dos librerías enlazadas en Figma: Font Awesome 7 para íconos de interfaz y Round World Flags para banderas circulares.

Resumen

El kit no dibuja un set propio de glifos: consume dos librerías publicadas y enlazadas al archivo Jetsmart UI Kit v1.0. Font Awesome 7 cubre acciones, navegación y estados de producto. Round World Flags cubre países y territorios en formato circular. Cada librería se inserta desde Assets; no se importa un SVG suelto ni se redibuja el pictograma a mano.

Round World Flags

Librería de banderas circulares para selectores de país, idiomas y contextos de ruta. En el kit se documentan más de 250 instancias (países, territorios y organizaciones). El componente se elige por nombre de país, no por código ISO escrito a mano en un texto.

  • Usar Round World Flags cuando el dato es un país o territorio.
  • Mantener el formato circular del componente; no recortar a rectángulo.
  • No sustituir una bandera por un emoji de texto ni por una imagen raster suelta.
  • No usar Font Awesome Brands como reemplazo de una bandera de país.

Buenas y malas prácticas

Tres pares que contrastan el uso correcto de las librerías con el error equivalente. El impacto aparece al actualizar la librería, al auditar Assets o al pasar a desarrollo.

01 · Componente de librería

Instanciar desde Assets, no pegar un SVG

El ícono del kit es una instancia del componente Font Awesome. Un SVG suelto se ve igual en la primera revisión y se desconecta de actualizaciones, nombres y estilos del pack.

Instancia Font Awesome Icon

icon-name: plane

Assets → Font Awesome Icon · icon-name plane

Familia, estilo y escala siguen al componente. Un cambio de pack se propaga.

SVG pegado en el frame

vector suelto

Path local · sin icon-name · sin pack

Visualmente similar. No hereda updates de la librería ni el contrato de nombre para desarrollo.

02 · Duotone completo

Las dos capas llevan el mismo icon-name

En Duo, la capa principal usa # y la secundaria ##. Dejar una vacía o con otro nombre rompe el glifo.

Ambas capas con house

icon-name# · house icon-name## · house

Family: Classic Duotone · Style: Solid

Las dos capas resuelven el mismo glifo con opacidades distintas.

Solo la capa principal

icon-name# · house icon-name## · (vacío)

Duotone incompleto

El render queda a medias o desaparece una capa. Tras cambiar de Mono a Duo hay que reescribir ambos campos.

03 · Bandera no es Brands

País → Round World Flags; marca → Font Awesome Brands

Un selector de país usa la bandera circular. El logo de una red social o marca usa el pack Brands. Mezclarlos confunde el dato.
